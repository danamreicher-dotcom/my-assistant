# VEYNE - תיקיית ידע מרכזית

**מה זה:** כל מה שידוע על VEYNE, מותג ציפורניים להדבקה של דנה רייכר, מאוגד במקום אחד. נאסף 7.9.2026 מ-Shopify, Gmail, Canva והאתר.

## תמונת מצב ב-30 שניות
- **מה:** ציפורניים להדבקה Soft Gel, 20 גוונים, 87 ₪ לערכה. מיובא מסין (Easywell Beauty / Shanghai Rainbud). נמכר ב-weareveyne.com.
- **מתי:** השקה 21.6.2026 (83 הזמנות ביום אחד). השקה מחדש 24.8 עם 10 צבעים חדשים.
- **כמה:** 234 הזמנות, ~43,000 ₪, 222 לקוחות, 38% חוזרות באוגוסט. 61% מהתנועה מאינסטגרם.
- **מה כואב:** Blanc ו-Rosé (המובילים) אזלו שוב. רגולציה תקועה מ-10.8. לקוחה מחכה 7 שבועות לתשובה. מנוי Shopify קופץ למחיר מלא ב-19.9.
- **מה חסר לגמרי:** מחירי ספק, MOQ, כל התכתובת עם היצרן (בוואטסאפ), שיווק ממומן (אין), קבצים ב-Drive (אין).
